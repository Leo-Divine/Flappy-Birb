# Flappy-Birb
Just a flappy bird game

## How to set up for showcase
Copy the code on your local device and run the HTML file.

If you plan on letting the kids mess with the code, I highly recommend you create backups of the code ahead of time to ensure that if something is ruined, you can use a fresh copy.

!!! - If you plan of letting the kids mess with the code, you must remove the .git file from the directory. They can not be allowed to push their changes to github.
